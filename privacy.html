Privacy Policy

Last updated: November 2026

The Curio Nova publishing tool is a private tool used by the owner of the Curio Nova YouTube channel to upload and schedule the channel's own videos.

What the tool accesses

The tool uses Google OAuth and the YouTube Data API only to upload and schedule videos on the owner's own YouTube channel. It requests the permission needed for uploading and nothing else.

Data we collect

We do not collect, store, sell or share personal data of visitors or viewers. This website has no accounts, forms or tracking. The owner's access tokens are kept as encrypted secrets in the code repository and are never shared with anyone.

Google and YouTube

The tool uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
